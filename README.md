# Nubisco Homebrew tap

Formulae for Nubisco's command-line products.

```sh
brew install nubisco/tap/alter
```

| Formula | Product |
| --- | --- |
| `alter` | Nubisco Alter, your second brain, running on your own machine. Keep it running with `brew services start alter`, then open it with `alter ui`. |

The formulae are generated by each product's release script from the signed
archives on downloads.nubisco.io. Do not edit them by hand.
